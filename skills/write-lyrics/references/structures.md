# Song Structure Menu

Pick deliberately. Rotate away from whatever the last 1–2 songs used.

| | Structure | Shape | Best for |
|---|---|---|---|
| **A** | Standard pop | V → PC → C → V → PC → C → B → C → O | Momentum + clear hook return. Fine when earned, lazy when defaulted. |
| **B** | Chorus-first | C → V → C → V → C → B → C | Hook so strong it needs no warm-up. |
| **C** | Verses only | V → V → V (optional short tag) | Narrative, folky, storytelling. No hook required. |
| **D** | Pre-chorus becomes chorus | V → PC → V → PC → (PC elevates to C) → B → C | Slow builds; don't give the peak away early. |
| **E** | Bridge as climax | V → C → V → C → B (end, or soft tag) | The bridge IS the resolution. Chorus never returns. Bold. |
| **F** | Tag outro | … → C → Tag (one phrase, repeated, decaying) | Songs that live in your head after they end. |
| **G** | A-A-B-A | Section A → A → B → A | Classic/jazz standard, ballads, melodic repetition. |
| **H** | Through-composed | Continuous; no full-section repeats | Ambitious narrative. Risky; unforgettable when it works. |
| **I** | Single-verse vignette | One verse (+ optional refrain) | Sub-90-second mood pieces, interludes. |
| **J** | Spoken verses / sung chorus | Spoken V → Sung C → … | Confessional voice-memo energy. |
| **K** | Verse-verse-chorus | V → V → C → V → C → (B) → C | Hip-hop, folk; verses carry the weight. No pre-chorus. |
| **L** | Reverse build | Big open → stripped middle → rebuild | Subverted expectations, emotional rug-pull. |

## Genre starting points (not mandates)

| Genre | Try first |
| --- | --- |
| Rap / hip-hop | K, C, J |
| Folk | G, C, K |
| Country | K, A |
| Rock | A, B |
| Pop | A, B, F |
| R&B | A, D |
| Singer-songwriter | A, H, C |
| Electronic / ambient | I, F, H |

## Choosing

1. Name the seed (best line/section) first.
2. Ask: does the seed need a runway (A/D), an immediate hit (B), or is it a story (C/H/K)?
3. Check recent songs — lean away from the last structure used.
4. If the obvious shape feels stale, search real references ("songs that open on the chorus," "through-composed pop") and let what you find bend it.
